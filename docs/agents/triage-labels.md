# Etykiety triage

| Wartość pola `Status` | Znaczenie |
|---|---|
| `needs-triage` | Zadanie czeka na kwalifikację. |
| `needs-info` | Do podjęcia decyzji brakuje informacji. |
| `ready-for-agent` | Kryteria wystarczają do samodzielnego wykonania zadania przez agenta po zamknięciu zależności. |
| `ready-for-human` | Wykonanie wymaga pracy człowieka, np. terenowego potwierdzenia wylotów. |
| `wontfix` | Podjęto decyzję o rezygnacji z realizacji. |
